# Code of conduct

tzMCP welcomes people of all backgrounds and experience levels. This code applies to project issues, pull requests, discussions, and other project spaces.

## Expected behavior

- Be respectful, patient, and constructive. Critique ideas and code without attacking people.
- Respect differences in experience, communication style, identity, and accessibility needs.
- Respect privacy. Do not share someone else's personal information or private traffic.
- Keep discussions relevant and respect the maintainer's decisions and limited time.

Harassment, discrimination, threats, sexual harassment, personal attacks, and deliberate disruption are not acceptable.

## Reporting and enforcement

Report concerns privately to [taggedzi.mpc@gmail.com](mailto:taggedzi.mpc@gmail.com). Include links or a brief description and only the information needed to understand the concern. Do not post sensitive details publicly.

The maintainer may edit or remove content, close or lock discussions, or restrict participation as appropriate. Reports will be handled as privately as practical, but absolute confidentiality cannot be guaranteed.

This is a solo-maintained project with limited availability. There is no guaranteed response time, continuous moderation, or promise that every report will receive a response. This reporting channel is not an emergency service.
